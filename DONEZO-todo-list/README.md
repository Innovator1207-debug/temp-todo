# DONEZO — React To-Do List

A clean, responsive to-do list built with React + Vite.

## Features
- Add, edit, complete and delete tasks
- Search and filter
- Priority levels
- Due dates and overdue indicator
- Progress percentage
- Dark/light mode
- LocalStorage persistence
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

The production files will be generated in `dist/`.
